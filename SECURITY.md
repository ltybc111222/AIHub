# Безопасность

## Как сообщить об уязвимости

Не создавайте публичный issue. Используйте приватный канал GitHub: вкладка **Security**, затем **Report a vulnerability**.

В отчёте укажите версию расширения, браузер, шаги воспроизведения и возможные последствия.

## Что считается уязвимостью

Помимо обычных дефектов безопасности, уязвимостью считается любое нарушение принципов из [README](README.md):

- сетевой запрос расширения куда-либо, кроме страницы сервиса, с которой работает пользователь;
- передача текста запросов, ответов, кук или токенов за пределы браузера;
- выполнение кода, которого нет в репозитории;
- права в манифесте шире, чем нужно для заявленных функций;
- расхождение опубликованной сборки с исходным кодом.
