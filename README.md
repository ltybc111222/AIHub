# AIHub (ИИХаб)

Браузерное расширение, которое собирает ваши ИИ-ассистенты в одном месте: один запрос уходит сразу в несколько чатов, а вы работаете со своими аккаунтами так же, как обычно.

> **Статус:** проектирование. Кода пока нет, идёт разведка и планирование. Ход работ: [docs/00-project-plan.md](docs/00-project-plan.md).

*AIHub is a free, open-source browser extension that lets you use several AI assistants side by side with your own accounts. No backend, no telemetry, no commerce. The project is at the design stage.*

## Принципы

Это не пожелания, а ограничения, которые проверяются по коду и манифесту.

1. **Никакой коммерции.** Расширение бесплатное. Нет рекламы, платных функций, партнёрских ссылок и продажи данных.
2. **Никакого сбора данных.** Нет телеметрии, аналитики и отчётов об ошибках. Тексты запросов и ответов не покидают ваш браузер и страницу сервиса, которому вы их сами отправили.
3. **Нет своего сервера.** У проекта нет бэкенда. Расширению некуда что-либо отправлять.
4. **Минимальные права.** Доступ только к сайтам поддерживаемых ассистентов, и каждый сервис вы включаете сами.
5. **Только видимый интерфейс.** Расширение делает то же, что сделали бы вы руками: вводит текст в поле и читает ответ со страницы. Внутренние API сервисов и сессионные токены не используются.
6. **Одно действие пользователя равно одной отправке.** Никаких фоновых запросов, циклов и обхода лимитов.
7. **Проверяемость.** Открытый код, никакого удалённо загружаемого кода, воспроизводимая сборка: любой может собрать расширение из исходников и сверить с опубликованной версией.

## Поддерживаемые сервисы (план первой версии)

- Claude
- ChatGPT
- DeepSeek

## Чего проект не делает

- Не даёт бесплатного доступа к платным моделям и не обходит ограничения сервисов.
- Не хранит и не передаёт ваши пароли, куки и ключи.
- Не заменяет аккаунты: для каждого сервиса нужен ваш собственный вход.

## Ответственность пользователя

Вы используете сторонние сервисы на их условиях. Перед использованием расширения ознакомьтесь с пользовательскими соглашениями этих сервисов.
